# Jumpzys Vortex

Official public release and update repository for **Jumpzys Vortex**.

This repo is used only for public downloads, update manifests, and release notes. The main source code is kept private.

## Latest Release

**Version:** 2.2.0
**Release:** https://github.com/Jumpzyy/Jumpzys-vortex/releases/tag/v2.2.0

## Download

Download the latest Windows build from the GitHub Releases page:

https://github.com/Jumpzyy/Jumpzys-vortex/releases/latest

## Requirements

* Windows 10/11 x64
* Administrator permissions for system/network optimisation features

## Update Files

* `update.xml` - updater manifest for the app
* `latest.json` - JSON update manifest for future updater support

## Safety Notes

Only download Jumpzys Vortex from this official GitHub repository. Some Windows SmartScreen or antivirus warnings may appear while the app is new or unsigned.
